# grandauto19.ru — цены проката (rental_car)

Копия файлов темы `grandauto`, отвечающих за цены автомобилей проката.
Живой сайт: https://grandauto19.ru

## Как устроены цены

Цены хранятся в ACF-полях записи типа `rental_car`:

| Период | Базовый сезон | Низкий сезон |
|---|---|---|
| 1-3 суток | `price_st_1_3` | `price_low_1_3` |
| 4-8 суток | `price_st_4_8` | `price_low_4_8` |
| 9-15 суток | `price_st_9_15` | `price_low_9_15` |
| 16-30 суток | `price_st_16_30` | `price_low_16_30` |
| 30+ суток | `price_st_30` | `price_low_30` |

Базовые поля заведены через админку ACF (группа «Арендный автомобиль»),
поля низкого сезона регистрируются кодом в `includes/acf-fields.php`.

## Два способа править цены

1. **По одной машине** — страница автомобиля в админке: блоки
   «Арендный автомобиль» и «Цены низкого сезона» идут друг за другом.
   В списке автомобилей выведены колонки с обеими таблицами цен,
   подозрительные значения низкого сезона подсвечены красным.
2. **Массово** — `update_prices_script.php`. Таблица `$PRICES` в начале файла
   правится через «Внешний вид → Редактор тем», затем скрипт открывается по
   адресу `/wp-content/themes/grandauto/update_prices_script.php`: он
   показывает предпросмотр изменений и пишет в базу только по кнопке.
   Доступ — только авторизованным пользователям с правом `edit_posts`.

## Важно про публичный сайт

Страницы `/prokat-avtonew/` и `/rental_car/<slug>/` отдаёт отдельный фронтенд
из каталога `/updated/` (его исходников в этом репозитории нет). Он читает
живые данные WordPress, поэтому базовые цены применяются сразу. Но цены
низкого сезона он **не берёт** из `price_low_*` — считает их как
«базовая − 15%». Чтобы сайт показывал значения из полей, нужна правка
фронтенда в `/updated/`.
