# Контент-завод (Content Factory)

Автоматическое производство YouTube-роликов на базе API [kie.ai](https://kie.ai):
сценарий → озвучка → видеоряд → субтитры → сборка → обложка → метаданные → шортсы.
Веб-панель с авторизацией, БД, файловое хранилище на NVMe-диске сервера, расписание по каналам.

## Что умеет

- **Каналы с вкладками.** Каждый канал — своя тематика, свои пресеты моделей, голос, стиль
  сценария и обложек, свой контент-план и расписание.
- **Контент-план.** Список книг/тем с датами. Можно вести руками или дописывать текстовой моделью
  (кнопка «Дописать план через AI»).
- **Расписание.** По каждому дню недели: сколько роликов и во сколько запускать. Планировщик
  проверяет расписание каждые 15 минут и сам ставит ролики в очередь.
- **Конвейер производства** (очередь задач + воркеры):
  1. `script` — текстовая модель пишет сценарий, разбитый на сцены (закадровый текст + описание кадра);
  2. `voice` — озвучка каждой сцены (ElevenLabs через KIE, автофолбэк на Gemini TTS);
  3. `visuals` — видеоряд для каждой сцены (Seedance через KIE);
  4. `assemble` — ffmpeg: нормализация, бесшовное зацикливание клипа под длину озвучки, склейка;
  5. `subtitles` — Whisper (faster-whisper) распознаёт речь, генерируются SRT/VTT/ASS,
     ASS опционально вшивается в картинку;
  6. `thumbnail` — обложка через nano-banana-2 (при сбое — кадр из ролика);
  7. `metadata` — заголовок, 4 варианта заголовка для A/B, описание с тайм-кодами, теги,
     закреплённый комментарий;
  8. `shorts` — модель выбирает сильные фрагменты по транскрипту с таймкодами, ffmpeg режет
     вертикальные 9:16 с субтитрами.
- **Актуальные цены KIE.** Тянутся из живого прайса KIE и обновляются раз в сутки (03:20 UTC),
  плюс кнопка «Обновить сейчас».
- **Каталог голосов** (67 голосов ElevenLabs + 12 голосов Gemini TTS) с прослушиванием превью.
- **Хранилище.** Все артефакты лежат на диске сервера, в панели — просмотр видео прямо в браузере
  (с перемоткой) и ссылки на скачивание MP4 / обложки / SRT / VTT / шортсов.
- **Журнал** по каждому ролику и общая очередь задач с ошибками.

## Требования

Ubuntu 24.04 LTS, root-доступ. Скрипт установки сам поставит: Python 3.12, ffmpeg, шрифты,
виртуальное окружение, faster-whisper, systemd-сервис и ротацию логов.

## Установка

```bash
git clone -b claude/content-factory-server-0qz0yw https://github.com/aklex1/grandauto.git /opt/contentfactory
cd /opt/contentfactory
KIE_API_KEY=ваш_ключ CF_ADMIN_PASSWORD=ваш_пароль bash deploy/install.sh
```

Скрипт напечатает адрес панели, логин и пароль. Если `CF_ADMIN_PASSWORD` не задать — пароль
сгенерируется автоматически и будет выведен в конце установки.

## Управление

```bash
systemctl status contentfactory      # состояние
systemctl restart contentfactory     # перезапуск
journalctl -u contentfactory -f      # живой лог
tail -f /var/lib/contentfactory/logs/app.log
bash /opt/contentfactory/deploy/update.sh   # обновление кода из git
```

## Структура данных

```
/opt/contentfactory/                 код и venv
/etc/contentfactory.env              переменные окружения (секреты, 600)
/var/lib/contentfactory/
    contentfactory.db                SQLite (WAL)
    media/<канал>/<id ролика>/       video.mp4, thumbnail.jpg, subtitles.srt/.vtt/.ass,
                                     audio/scene_XX.*, clips/scene_XX.mp4, shorts/short_XX.mp4
    models/                          веса Whisper
    logs/app.log                     журнал сервиса
    tmp/                             рабочие файлы сборки (чистятся автоматически)
```

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `KIE_API_KEY` | ключ API kie.ai | — |
| `CF_ADMIN_USER` / `CF_ADMIN_PASSWORD` | доступ в панель | `admin` / генерируется |
| `CF_SECRET_KEY` | подпись сессионных cookie | генерируется |
| `CF_DATA_DIR` | каталог хранилища | `/var/lib/contentfactory` |
| `CF_DB_URL` | строка подключения к БД (можно PostgreSQL) | SQLite в `CF_DATA_DIR` |
| `CF_HOST` / `CF_PORT` | адрес веб-панели | `0.0.0.0` / `80` |
| `CF_WORKERS` | воркеров очереди | `2` |
| `CF_WHISPER_MODEL` | модель ASR (`tiny`…`large-v3`) | `small` |
| `CF_WHISPER_DEVICE` / `CF_WHISPER_COMPUTE` | `cpu`/`cuda`, `int8`/`float16` | `cpu` / `int8` |
| `CF_WHISPER_ENABLED` | выключить ASR (тайминги считаются по сценам) | `1` |

## Модели KIE по умолчанию

| Роль | Модель | Цена (на момент настройки) |
|---|---|---|
| Текст (сценарии, план, метаданные, шортсы) | `gemini-3-8-flash-openai` | $0.225 / $1.125 за 1M токенов |
| Видео | `bytedance/seedance-1.5-pro` | от 1.75 кредита/сек (480p без звука) |
| Обложки | `nano-banana-2` | 8 кредитов за изображение (1K) |
| Озвучка | `elevenlabs/text-to-speech-multilingual-v2` | 12 кредитов / 1000 знаков |
| Озвучка (фолбэк) | `google/gemini-3-1-flash-tts` | 2800 кредитов / 1M аудио-токенов |

Все модели переключаются в панели: «Настройки канала» → «Модели генерации», список подтягивается
из KIE автоматически. Актуальные цены — на вкладке «Цены KIE».
