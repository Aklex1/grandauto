# Контент-завод (Content Factory)

Автоматическое производство YouTube-роликов на базе API [kie.ai](https://kie.ai):
сценарий → озвучка → видеоряд → субтитры → сборка → обложка → метаданные → шортсы.
Веб-панель с авторизацией, БД, файловое хранилище на NVMe-диске сервера, расписание по каналам.

## Что умеет

- **Каналы с вкладками.** Каждый канал — своя тематика, свои пресеты моделей, голос, стиль
  сценария и обложек, свой контент-план и расписание.
- **Контент-план.** Список книг/тем с датами. Можно вести руками или дописывать текстовой моделью
  (кнопка «Дописать план через AI»).
- **Расписание.** По каждому дню недели: сколько роликов и во сколько запускать. Планировщик
  проверяет расписание каждые 15 минут и сам ставит ролики в очередь.
- **Своя библиотека видео.** В канал можно загрузить собственные футажи (файлами или по прямым
  ссылкам) и размечать их тегами. Видеоряд собирается в одном из трёх режимов: только генерация,
  только библиотека (бесплатно) или смешанный с заданной долей. Фрагменты режутся случайными
  непересекающимися кусками, поэтому в одном ролике повторов нет, а теги подбирают футаж
  под смысл сцены.
- **Пакетный импорт со стоков (бета).** Отдельная вкладка «Стоки» в карточке канала: поиск по
  Pexels и Pixabay, превью выдачи, отметка нужных роликов и импорт пачкой в фоне. Теги
  проставляются автоматически из поискового запроса, ориентация подставляется под формат канала.
  Оба сервиса отдают видео по лицензии, разрешающей коммерческое использование. Ключи задаются
  в «Настройках», оба бесплатные.
- **Контроль места на диске.** Свободное место видно в шапке панели на любой странице.
  Во вкладке «Библиотека видео» есть карточка «Хранилище»: сколько занимают ни разу не
  использованные футажи, отключённые, импортированные со стоков, записи без файла и файлы без
  записи — каждую группу можно удалить одной кнопкой. Загрузка новых футажей останавливается
  сама, когда свободного места остаётся меньше неснижаемого остатка из настроек.
- **Пересборка отдельной сцены.** Под каждой готовой сценой раскрывается блок: правка
  промпта видеоряда и текста озвучки, выбор модели видео, модели речи и голоса из справочника
  KIE. На выходе — законченный кусок с видеорядом, озвучкой, субтитрами и копией с фоновой
  музыкой. Озвучка переделывается только при изменении текста, голоса или модели речи.
- **Сцена как готовый шортс.** У каждой готовой сцены есть кнопка «Собрать шортс»: вертикальный
  файл с заголовком в кадре, субтитрами и музыкой плюс обложка. Обложку рисует nano banana 2
  (яркая вертикальная картинка по теме сцены), заголовок накладывается своим шрифтом поверх —
  кириллицу генераторы изображений рисуют плохо. Если генератор не ответил, берётся кадр из
  самой сцены. Кадры заново не генерируются, поэтому сборка шортса кредитов почти не стоит.
- **Видеоряд без отмотки назад.** Сцена закрывается разными кадрами. Если сгенерированных
  кадров не хватает на всю озвучку, недостаток добирается вариациями прохода — зеркало,
  наезд, отъезд, панорама, — а не реверсом и не зацикливанием одного куска.
- **Субтитры в стиле шортсов.** Крупный жирный текст без плашки, толстая обводка с тенью,
  короткие реплики и подсветка звучащего слова акцентным цветом. Классическая плашка
  доступна переключателем в настройках канала.
- **Конвейер производства** (очередь задач + воркеры):
  1. `script` — текстовая модель пишет сценарий, разбитый на сцены (закадровый текст + описание кадра);
  2. `voice` — озвучка каждой сцены (ElevenLabs через KIE, автофолбэк на Gemini TTS);
  3. `visuals` — видеоряд для каждой сцены: генерация (Seedance через KIE) и/или нарезка
     из загруженной библиотеки;
  4. `assemble` — каждая сцена собирается в **отдельный законченный ролик**: клипы
     подгоняются под длину озвучки бесшовным зацикливанием, поверх ложатся субтитры;
  5. `metadata` — заголовок, 4 варианта для A/B, описание с тайм-кодами, теги,
     закреплённый комментарий и короткая фраза для обложки;
  6. `thumbnail` — обложка через nano-banana-2 с крупным заголовком поверх картинки
     (при сбое генератора — кадр из сцены);
  7. **сборка длинного ролика вручную**: в панели отмечаются нужные сцены и собирается
     итоговый ролик в выбранном составе, с фоновой музыкой, общими SRT и VTT;
  8. `shorts` — модель выбирает сильные фрагменты по транскрипту с таймкодами, ffmpeg режет
     вертикальные 9:16 с субтитрами и заголовком фрагмента.
- **Фоновая музыка.** Инструментальный трек под тематику канала генерируется через Suno
  внутри KIE и подмешивается под голос: уровень речи сохраняется, фон притапливается
  sidechain-компрессором, когда звучит голос. Треки переиспользуются между роликами канала.
- **Субтитры без ослышек.** Слова берутся из сценария, а тайминг — из распознавания речи,
  поэтому ошибки ASR не попадают в кадр. Текст ложится на полупрозрачную подложку,
  кегль считается от ширины кадра.
- **Актуальные цены KIE.** Тянутся из живого прайса KIE и обновляются раз в сутки (03:20 UTC),
  плюс кнопка «Обновить сейчас».
- **Каталог голосов** (67 голосов ElevenLabs + 12 голосов Gemini TTS) с прослушиванием превью.
- **Хранилище.** Все артефакты лежат на диске сервера, в панели — просмотр видео прямо в браузере
  (с перемоткой) и ссылки на скачивание MP4 / обложки / SRT / VTT / шортсов.
- **Журнал** по каждому ролику и общая очередь задач с ошибками.

## Требования

Ubuntu 24.04 LTS, root-доступ. Скрипт установки сам поставит: Python 3.12, ffmpeg, шрифты,
виртуальное окружение, faster-whisper, systemd-сервис и ротацию логов.

## Установка

```bash
git clone https://github.com/Aklex1/ContentFactory.git /opt/contentfactory
cd /opt/contentfactory
KIE_API_KEY=ваш_ключ CF_ADMIN_PASSWORD=ваш_пароль bash deploy/install.sh
```

Скрипт напечатает адрес панели, логин и пароль. Если `CF_ADMIN_PASSWORD` не задать — пароль
сгенерируется автоматически и будет выведен в конце установки.

## Управление

```bash
systemctl status contentfactory      # состояние
systemctl restart contentfactory     # перезапуск
journalctl -u contentfactory -f      # живой лог
tail -f /var/lib/contentfactory/logs/app.log
bash /opt/contentfactory/deploy/update.sh   # обновление кода из git
```

## Структура данных

```
/opt/contentfactory/                 код и venv
/etc/contentfactory.env              переменные окружения (секреты, 600)
/var/lib/contentfactory/
    contentfactory.db                SQLite (WAL)
    media/<канал>/<id ролика>/       video.mp4, thumbnail.jpg, subtitles.srt/.vtt/.ass,
                                     audio/scene_XX.*, clips/scene_XX.mp4, shorts/short_XX.mp4
    models/                          веса Whisper
    logs/app.log                     журнал сервиса
    tmp/                             рабочие файлы сборки (чистятся автоматически)
```

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `KIE_API_KEY` | ключ API kie.ai | — |
| `CF_ADMIN_USER` / `CF_ADMIN_PASSWORD` | доступ в панель | `admin` / генерируется |
| `CF_SECRET_KEY` | подпись сессионных cookie | генерируется |
| `CF_DATA_DIR` | каталог хранилища | `/var/lib/contentfactory` |
| `CF_DB_URL` | строка подключения к БД (можно PostgreSQL) | SQLite в `CF_DATA_DIR` |
| `CF_HOST` / `CF_PORT` | адрес веб-панели | `0.0.0.0` / `80` |
| `CF_WORKERS` | воркеров очереди | `2` |
| `CF_WHISPER_MODEL` | модель ASR (`tiny`…`large-v3`) | `small` |
| `CF_WHISPER_DEVICE` / `CF_WHISPER_COMPUTE` | `cpu`/`cuda`, `int8`/`float16` | `cpu` / `int8` |
| `CF_WHISPER_ENABLED` | выключить ASR (тайминги считаются по сценам) | `1` |

## Модели KIE по умолчанию

| Роль | Модель | Цена (на момент настройки) |
|---|---|---|
| Текст (сценарии, план, метаданные, шортсы) | `gemini-3-8-flash-openai` | $0.225 / $1.125 за 1M токенов |
| Видео | `bytedance/seedance-1.5-pro` | от 1.75 кредита/сек (480p без звука) |
| Обложки | `nano-banana-2` | 8 кредитов за изображение (1K) |
| Озвучка | `elevenlabs/text-to-speech-multilingual-v2` | 12 кредитов / 1000 знаков |
| Озвучка (фолбэк) | `google/gemini-3-1-flash-tts` | 2800 кредитов / 1M аудио-токенов |

Все модели переключаются в панели: «Настройки канала» → «Модели генерации», список подтягивается
из KIE автоматически. Актуальные цены — на вкладке «Цены KIE».
