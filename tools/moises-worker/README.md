# Обработчик очереди через веб-интерфейс студии

Временное решение, пока у разделения дорожек и шумоподавления нет рабочего API.
Заказ с сайта принимается и оплачивается как обычно, попадает в очередь,
а выполняется через браузер — вручную или полуавтоматически.

Скрипт снимает всю рутину вокруг: сам забирает очередь, скачивает исходник,
открывает студию и отправляет готовые дорожки обратно на сайт. Пользователь
получает их в истории и письмом, ничего не зная про кухню.

## Что нужно

* компьютер, который будет включён (на хостинге сайта браузер не поднять);
* браузер от playwright; если Chrome уже стоит отдельно — путь к нему
  можно передать переменной `GB_CHROME`;
* Python 3.9+;
* ключ доступа с правами владельца сайта — выпускается на странице
  `/api/` под администратором.

```
pip install playwright requests
playwright install chromium
```

## Первый запуск

```
set GB_KEY=gb_ваш_ключ          # Windows: set, macOS/Linux: export
python worker.py
```

Откроется браузер с постоянным профилем — войдите в студию один раз,
дальше вход запоминается. При каждом заказе скрипт печатает, какой файл
скачан и куда сохранить результат:

```
work/<номер заказа>/source.mp3   ← исходник
work/<номер заказа>/out/minus.mp3 ← минусовка
work/<номер заказа>/out/vocal.mp3 ← вокал
```

Как только файлы появятся в `out`, скрипт сам отправит их на сайт и закроет
заказ. Имена важны: `minus` и `vocal` для разделения дорожек, `clean` —
для очистки записи.

## Разовая проверка одного файла

Без очереди сайта, чтобы просто убедиться, что связка работает:

```
python worker.py --file "C:\Users\Automation Engineer\Downloads\Lumen_-_Tri_puti_(musmore.org).mp3"
```

Имя можно писать и без расширения — скрипт найдёт файл сам. Откроется
браузер со студией, минус сохраняете как `work/single/out/minus.mp3`,
скрипт покажет, что получил.

## Селекторы для автоматического режима

Я не могу подобрать их сам — доступа к вашему аккаунту у меня нет.
Скрипт соберёт кандидатов за вас:

```
python worker.py --inspect
```

Откроется браузер: войдите в студию, дойдите до экрана с загрузкой трека
и нажмите Enter в консоли. Рядом со скриптом появится `studio-dump.json`
со всеми полями загрузки и кнопками — пришлите его мне, и я соберу
`selectors.json`.

## Автоматический режим

`python worker.py --auto` пробует прокликать студию сам. Нужны селекторы
в `selectors.json` рядом со скриптом:

```json
{
  "upload_input": "input[type=file]",
  "ready_marker": "текст или селектор, появляющийся по готовности",
  "timeout_ms": 600000,
  "downloads": {
    "minus": "селектор кнопки скачивания инструментала",
    "vocal": "селектор кнопки скачивания вокала"
  }
}
```

Разметку студии меняют часто, поэтому селекторы придётся подправлять —
я их подобрать не мог, доступа к аккаунту у меня нет. Если автоматический
режим не справился, скрипт молча переходит в ручной и ждёт файлы в `out`.

## О чём стоит помнить

Автоматизация личного аккаунта чужого сервиса — против его правил, и за неё
аккаунт могут заблокировать. Ручной режим таких вопросов не вызывает: вы
просто работаете в студии руками, а скрипт занимается очередью и файлами.
Как только появится рабочий API (Music AI или другой), режим выключается
одной галкой в админке — страницы, цены и история останутся прежними.
