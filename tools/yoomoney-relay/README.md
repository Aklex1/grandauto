# Пересылка платежей сайта из обработчика KIE-бота

В настройках кошелька ЮMoney можно указать только один адрес уведомлений.
У вас там стоит `http://89.169.38.152:8000/yoomoney-webhook` — KIE-бот, и
менять этот адрес не нужно: он уже раздаёт чужие платежи по метке, так
подключён AI-коуч. Сайт подключается тем же способом.

## Что происходит

```
ЮMoney → KIE-бот /yoomoney-webhook
           ├── метка «ac.…»            → AI-коуч   (уже работает)
           ├── метка «topup_…»         → сайт      (добавляем)
           ├── метка «kie-neurohub|…»  → сайт      (добавляем)
           └── остальное               → логика бота, как была
```

Тело запроса пересылается байт в байт, поэтому подпись ЮMoney остаётся
проверяемой. Сайт по метке находит пользователя и пополняет ему баланс —
неважно, вошёл человек по почте, через ВК или из Telegram.

## Установка

Положите оба файла рядом с обработчиком бота и примените правку:

```bash
scp site_relay_snippet.py patch_kie_webhook_site.py root@89.169.38.152:/opt/src/kie_ai_bot/
ssh root@89.169.38.152
cd /opt/src/kie_ai_bot
python3 patch_kie_webhook_site.py <файл с обработчиком>.py --dry-run   # посмотреть
python3 patch_kie_webhook_site.py <файл с обработчиком>.py             # применить
python3 -m py_compile <файл с обработчиком>.py
systemctl restart kie-bot
```

Файл обработчика — тот же, куда вставляли пересылку коучу. Найти его:

```bash
grep -rln "yoomoney-webhook" /opt/src/kie_ai_bot --include=*.py
```

Повторный запуск ничего не меняет. Откат — `mv <файл>.py.bak <файл>.py`.

## Проверка

```bash
python3 site_relay_snippet.py
```

Печатает разбор меток и отправляет сайту уведомление с заведомо
несуществующим платежом. Ожидаемый ответ сайта:
`{"status":"ok","credited":false,...}` — связь есть, чужого не зачисляет.

Что происходит с настоящими платежами, видно в админке сайта:
«Звуки» → «Платежи по сервисам» — там и сводка по услугам, и журнал
последних уведомлений.

## Метки

| Префикс | Чей платёж |
|---|---|
| `ac.` | AI-коуч |
| `topup_wp_`, `topup_telegram_` | сайт: кабинет озвучки и микросервисы |
| `kie-neurohub\|` | сайт: раздел «Нейросети» |
| прочее | KIE-бот |

Проверка точная по префиксу: метка бота `kie-123` под правило сайта
`kie-neurohub|` не подпадает.
