# Витрина /updated/ — живые цены из админки

Витрина `/updated/` (страницы `/prokat-avtonew/` и `/rental_car/<slug>/`) —
статический HTML. Раньше цены были «запечены» в HTML при генерации, а низкий
сезон считался как «базовая − 15%», из-за чего ACF-поля `price_low_*` вообще
не влияли на сайт.

Теперь оба сезона берутся вживую из WordPress, править цены нужно только в
админке — на сервер заходить не требуется.

## Как это работает

1. **REST-эндпоинт** (в теме, `includes/acf-fields.php`):
   `GET https://grandauto19.ru/wp-json/grandauto/v1/prices`
   Отдаёт по каждому опубликованному авто:
   - `base` — базовый сезон (`price_st_1_3 … price_st_16_30`);
   - `low`  — низкий сезон (`price_low_1_3 … price_low_16_30`,
     пусто → базовая − 15%);
   - `silver` / `gold` — проценты скидок из настроек темы;
   - `info` — остальные данные карточки из ACF: `title`, `year`, `hp`
     (мощность), `transmission` (коробка), `wd` (привод), `gasoline`
     (расход), `driverplace` (руль), `pledge` (залог), `kasko`,
     `defence` (защита шин), `casco` (бейдж КАСКО, вкл/выкл).

2. **JS витрины** (`updated/js/car-page.js`, `updated/js/app.js`):
   при загрузке страницы запрашивают эндпоинт и подставляют данные.
   - Карточка авто: заголовок, год, таблица характеристик, залог, КАСКО,
     защита шин, бейдж КАСКО — из `info`; все 6 таблиц цен
     (Стандарт/Silver/Gold × базовый/низкий) строятся из `base`/`low`
     (Silver = ×(1−silver%), Gold = ×(1−gold%), округление вниз).
   - Каталог: заголовок, год, строка «год · коробка · привод», бейдж
     КАСКО, фильтр по коробке и цена «от N ₽/сут» (базовая 16-30).
   - Если эндпоинт недоступен — остаются данные, зашитые в HTML (фолбэк).

   **Фотографии не подтягиваются из админки** — остаются файлами витрины
   (`/updated/media/…`) с их адаптивными webp-вариантами. Это единственное,
   что пока правится не из админки; вынести фото в медиатеку WordPress —
   отдельная доработка (ухудшит оптимизацию картинок, поэтому по умолчанию
   оставлено как есть).

## Установка (разово)

Залить два файла в `/home/admin/web/grandauto19.ru/.../updated/js/`:
- `car-page.js`
- `app.js`

Эндпоинт уже развёрнут в теме. После заливки JS цены на витрине
подтягиваются из админки автоматически.

## Как менять цены (после установки — только админка)

- **По одной машине:** «Автомобили» → авто → блоки «Арендный автомобиль»
  (базовый сезон) и «Цены низкого сезона».
- **Массово:** `https://grandauto19.ru/wp-content/themes/grandauto/update_prices_script.php`
  (только для авторизованного администратора) — таблица всех цен обоих
  сезонов, предпросмотр и запись по кнопке.
- **Проценты Silver/Gold:** «Внешний вид» → «Настройка скидок».

Заходить на сервер и что-либо скачивать для правки цен больше не нужно.
