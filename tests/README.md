# Тесты завода

```
bash tests/run.sh                 # все
bash tests/run.sh test_youtube    # один
```

Каждый тест получает свой каталог данных через `CF_DATA_DIR`, так что настоящую
базу и хранилище они не трогают. Вместо KIE, Suno и Google поднимаются подставные
серверы: сеть наружу не нужна, денег тесты не тратят. Из внешнего нужны только
`ffmpeg` и `ffprobe` — звук и видео делаются и проверяются настоящими, потому что
проверять сборку роликов по заглушкам бессмысленно.

Тест считается пройденным, только если напечатал `ВСЁ ПРОШЛО`: иначе он мог
свалиться после последней проверки и остаться незамеченным.

| Файл | Что проверяет |
|---|---|
| `test_musicvideo.py` | длинный микс: переходы, громкость, замыкание заставки по измерению стыка, тайм-код с вычетом перекрытий, бесплатность пересборки, вкладки панели |
| `test_mv_import.py` | сборка из архива: что взято, что отброшено, досбор недостающего, наезд на картинку, ошибки загрузки |
| `test_mv_package.py` | настоящий пакет (слепок soul-notes-007): готовый мастер, дубли сырья, выбор плашки, тайм-код и текстовое исследование |
| `test_youtube.py` | публикация: обмен кода, загрузка с возобновлением через обрыв, метаданные, объяснение отказов, кнопка в панели |

**Почему они здесь, а не в черновиках.** Раньше тесты жили в рабочем каталоге
сессии. Каталог пересоздали — и тридцать пять тестов исчезли вместе с ним. Набор
проверок, который существует только в одном временном месте, набором проверок не
является.
