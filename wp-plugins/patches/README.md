# Правки в чужих плагинах на живом сайте

Эти изменения сделаны прямо на genius-bot.ru, в плагинах, которых нет в
этом репозитории. **Они потеряются при обновлении своего плагина** —
поэтому записаны здесь дословно, вместе с причиной.

Проверять после каждого обновления любого из перечисленных плагинов:

```bash
curl -s -D - -o /dev/null https://genius-bot.ru/ | grep -iE "^(cache-control|set-cookie)"
```

Если на главной снова появился `no-store` или cookie с `SESS` — правка
уехала, вернуть по этому файлу.

## 1. kie-tts-wp: цена озвучки 12 → 18 ₽ за 1000 знаков

Себестоимость у поставщика — 12 кредитов за 1000 знаков (≈5,4 ₽), при цене
12 ₽ оставалось 55%: самая слабая позиция в корзине. Новая цена даёт 70%.

Менять надо в четырёх местах сразу, иначе показанная и списанная цены
разойдутся:

| Файл | Было | Стало |
|---|---|---|
| `includes/class-kie-tts-api.php` | `$cost = $blocks * 12;` | `* 18` |
| `includes/class-kie-tts-api.php` | `return max(12, $cost);` | `max(18, …)` |
| `assets/js/main.js` | `Math.max(12, blocks * 12)` | `Math.max(18, blocks * 18)` |
| `assets/js/main.js` | `от 12 ₽ за 1000 символов` | `от 18 ₽ …` |
| `includes/class-kie-tts-pages.php` | `Базовая стоимость: 12 ₽ …` | `18 ₽ …` |

## 2-4. Сессия только там, где она нужна

Три плагина открывали PHP-сессию на `init` **на каждом запросе сайта** —
включая `robots.txt` и каждый обход роботом. Следствия:

* `session_start()` всегда добавляет `no-store, no-cache` — кэширование
  было запрещено всему сайту, и ни кэширующий плагин, ни CDN не работали;
* PHP держит блокировку на файле сессии всё время запроса, то есть
  одновременные запросы одного посетителя выстраивались в очередь;
* файлы сессий копились на каждый обход робота, с недельным сроком жизни.

После правки первый байт на главной упал с 2,66 до 1,82 с, и на обычных
страницах заголовка `cache-control` не стало вовсе.

Проверять `is_page()` на `init` нельзя — запрос там ещё не разобран,
поэтому условие построено по адресу.

### Общий вид правки

В главном файле плагина безусловный вызов

```php
add_action('init', '<префикс>_start_session', 1);
```

заменяется на условный:

```php
add_action('init', '<префикс>_maybe_start_session', 1);

function <префикс>_needs_session() {
    $action = isset($_REQUEST['action']) ? (string) $_REQUEST['action'] : '';
    if (strpos($action, '<префикс ajax>') === 0) {
        return true;
    }
    $uri  = isset($_SERVER['REQUEST_URI']) ? (string) $_SERVER['REQUEST_URI'] : '';
    $path = strtolower((string) wp_parse_url($uri, PHP_URL_PATH));
    if ($path === '<страница>' || $path === '<страница>/') {
        return true;
    }
    return strpos($path, '/wp-json/<пространство REST>/') === 0;
}

function <префикс>_maybe_start_session() {
    if (<префикс>_needs_session()) {
        <префикс>_start_session();
    }
}
```

### Значения по плагинам

| Плагин | Префикс | Запросы ajax | Страница | Маршруты REST |
|---|---|---|---|---|
| `genius-pdf-online` | `genius_pdf` | `genius_pdf_` | `/pdf-online` | `/wp-json/genius-pdf/` |
| `kie-neurohub` | `kie_neurohub` | `kie_neurohub_` | `/neurohub` | `/wp-json/neurohub/` |
| `wheel-fitment` | `wheel_fitment` | `wheel_fitment_` | `/showwheel` | `/wp-json/wheel-fitment/` |

### Что проверено отдельно

* **Скачивание готового PDF** сессии не требует: там одноразовая ссылка с
  nonce и transient.
* **Приём оплаты нейрохаба** работает только по метке платежа и `$_SESSION`
  не трогает. Это важно: сайт вызывает его внутренним запросом, и в адресе
  тогда стоит наш маршрут, а не его, — условие по адресу сессию не откроет.
* Все три страницы сервисов после правки отдают свою разметку и сохраняют
  свою сессию.
