# Тарифы партнёрской программы

Обычный партнёр получает **10%** со всех покупок приведённого пользователя.
Вебмастер, пришедший по особой ссылке, — **50% с первого депозита** реферала
и **20% со всех последующих**.

## Ссылка для вебмастеров

```
https://t.me/Neuro_HubAI_bot?start=wm_ufoydoydoy
```

Часть после `wm_` — метка источника: по ней видно, откуда пришёл вебмастер.
Под разные площадки делаются разные ссылки, менять код для этого не нужно:

```
?start=wm_ufoydoydoy      -> источник «ufoydoydoy»
?start=wm_cpaclub         -> источник «cpaclub»
```

Перешедший по такой ссылке сразу получает сообщение о подключении к программе
и своих условиях. Тариф закрепляется за ним навсегда; повторный переход по
ссылке ничего не меняет и не понижает.

## Как считается комиссия

| Событие                          | Обычный партнёр | Вебмастер |
|----------------------------------|-----------------|-----------|
| Первый депозит реферала          | 10%             | **50%**   |
| Все последующие покупки          | 10%             | **20%**   |

С депозита в 1000₽ вебмастер получает 500₽ за первую покупку и по 200₽ за
каждую следующую.

Первая покупка определяется по флагу `first_payment_received` в таблице
`partner_program` — тому же, что использовался для повышенной ставки раньше.

## Где что лежит

* `partner_tiers.py` — тарифы, разбор ссылки, расчёт ставки;
* таблица `partner_tiers` в MySQL — кто на каком тарифе и из какого источника
  (создаётся автоматически при старте);
* `database.py` — `add_referral` берёт ставку из тарифа партнёра,
  `update_partner_commission` выбирает между первой и последующими.

Прежнее поведение сохранено: партнёры без записи в `partner_tiers` работают
на стандартных 10%, отдельный случай с 15% для `vlad_myrsin` тоже остался.

## Добавить тариф или изменить ставки

Ставки заданы в `partner_tiers.py`:

```python
TIERS = {
    "standard": (10.0, 10.0),   # первый депозит, дальше
    "webmaster": (50.0, 20.0),
}
```

Новый тариф — новая строка в этом словаре плюс свой префикс ссылки, если нужен
отдельный вход.

## Посмотреть, кто подключился

```sql
SELECT partner_telegram_id, partner_username, tier, source, created_at
FROM partner_tiers ORDER BY created_at DESC;
```
