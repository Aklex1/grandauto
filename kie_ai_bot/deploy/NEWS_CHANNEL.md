# Канал «Нейросети»: контент-план и новости

Три поста в сутки в группу `-1001711115341` (@group_number_0001), где бот
администратор: **один из контент-плана** и **две новости** с русскоязычных
порталов про ИИ.

## Расписание

| Время (МСК) | Время (UTC) | Что выходит        |
|-------------|-------------|--------------------|
| 10:00       | 07:00       | пост из плана      |
| 15:00       | 12:00       | новость            |
| 19:00       | 16:00       | новость            |

Часы задаются в `NEWS_SCHEDULE_HOURS` (в UTC, через запятую). Воркер сверяется
с расписанием раз в `NEWS_TICK_INTERVAL` секунд и публикует, если за сутки
норма ещё не выбрана — поэтому перезапуск бота не приводит ни к пропуску,
ни к дублю.

## Контент-план

`content_plan.json` — 90 постов на три месяца, шесть рубрик по кругу:

* 🧠 Разбор нейросети — что за модель, что умеет, где ошибается
* ⚡ Промпт дня — готовая формулировка с пояснением, почему она работает
* 💡 Как применить — прикладной сценарий
* 🎯 Ошибки новичков — типовые промахи и как их избежать
* 📊 Сравнение — что выбрать под задачу
* 🔮 Тренды и будущее — куда движется рынок

Посты идут по порядку, каждый ровно один раз: номер последнего
опубликованного хранится в базе. Когда план закончится, в лог уйдёт запись —
можно дописать файл и продолжить с того же места.

Формат записи:

```json
{
  "rubric": "⚡ Промпт дня",
  "title": "Заголовок",
  "text": "Текст поста",
  "cta": "Попробовать в боте"
}
```

## Источники новостей

Профильные ленты берутся целиком, общетехнические — только материалы про ИИ,
по ключевым словам в заголовке и описании.

| Источник      | Профильный | Картинки в ленте |
|---------------|------------|------------------|
| Хабр (ИИ)     | да         | почти всегда     |
| Хабр (МО)     | да         | всегда           |
| NeuroHive     | да         | редко            |
| 3DNews        | нет        | всегда           |
| iXBT          | нет        | всегда           |
| CNews         | нет        | через страницу   |
| Ferra         | нет        | всегда           |
| vc.ru         | нет        | часто            |
| RB.RU         | нет        | всегда           |
| Tproger       | нет        | через страницу   |
| Naked Science | нет        | всегда           |

Из общих лент материал берётся, только если тема заявлена **в заголовке**
(`NEWS_STRICT_TITLE_MATCH=1`), и проходит два фильтра:

1. **Отсев железа и гаджетов.** Заголовки про ноутбуки, смартфоны, видеокарты,
   процессоры, распродажи отбрасываются сразу — даже когда в названии продукта
   есть «AI» (`Ryzen AI`, `Core Ultra`). Список в `HARDWARE_STOP_WORDS`.
2. **Точные признаки темы.** Слово должно означать именно ИИ: «нейросеть»,
   «искусственный интеллект», «языковая модель», «OpenAI», «ChatGPT» и подобные.
   Общие «ai», «обучение», «языковой» из списка убраны намеренно — по ним
   в ленту лезли обзоры процессоров и статьи про курсы. Список в `AI_KEYWORDS`.

Если картинки нет в самой ленте, она берётся из `og:image` страницы
материала. Если и там пусто — пост выходит текстом.

## Ссылки в постах

**Ссылок на сторонние сайты в постах нет.** Источник указывается только
словом — «Источник: Хабр». Превью внешних страниц отключено. Единственная
ссылка в посте — на ваш бот, её текст задаётся в `NEWS_BOT_CTA`.

Убрать упоминание источника совсем: `NEWS_SHOW_SOURCE_NAME=0`.
Убрать призыв с ссылкой на бота: `NEWS_BOT_CTA=`.

Список правится в `news_sources.py`, ключевые слова отбора — там же
в `AI_KEYWORDS`.

## Защита от повторов

Каждый опубликованный материал запоминается дважды:

* по **ссылке**, очищенной от utm-меток, якорей и параметров `from`/`ref`;
* по **отпечатку заголовка** — набору значимых слов длиннее трёх букв.

Поэтому одна и та же новость не выйдет повторно ни с другой ленты, ни с
изменённой ссылкой, ни после перезапуска бота: база на диске переживает
рестарт. В пределах одного прохода тоже стоит проверка, так что две новости
за день не окажутся об одном и том же.

Посмотреть, что уже выходило:

```bash
sqlite3 /opt/kie_ai_bot/news.db \
  "SELECT kind, source, substr(title,1,60), published_at
   FROM news_posts ORDER BY id DESC LIMIT 20;"
```

## Включение

```
NEWS_ENABLED=1
NEWS_CHAT_ID=-1001711115341
NEWS_SCHEDULE_HOURS=7,12,16
NEWS_PLAN_PER_DAY=1
NEWS_PER_DAY=2
```

Файл `content_plan.json` должен лежать по пути из `NEWS_PLAN`
(по умолчанию `/opt/kie_ai_bot/content_plan.json`) — установщик копирует его
вместе с кодом.

После правки `.env` — `systemctl restart kie-bot`. В логе появится строка
`[новости] запущено: канал ..., расписание [7, 12, 16] UTC`.
