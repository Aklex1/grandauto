# Серия публикаций в тему группы

Новая тема в группе пустая, и первый зашедший видит белый лист. Один
большой пост этого не чинит: по ленте видно, что жизни нет. Поэтому бот
выкладывает двенадцать коротких публикаций, разложенных на пять дней с
разным временем — лента наполняется так, как наполнялась бы живым
автором.

## Включение

В `/opt/kie_ai_bot/.env`:

```
SEED_ENABLED=1
SEED_CHAT_ID=-1004407841852
SEED_THREAD_ID=2
```

`SEED_CHAT_ID` и `SEED_THREAD_ID` уже стоят по умолчанию именно такими:
адрес `t.me/c/4407841852/2` означает чат `-100` + `4407841852` и тему `2`.
Менять их нужно только для другой группы или темы.

После правки — `systemctl restart kie-bot`. В логе появится:

```
[серия] запущена: чат -1004407841852, тема 2, постов 12, уже вышло 0, отсчёт с …
```

Бот должен состоять в группе и иметь право писать в темы.

## Расписание

Отсчёт привязан к часу первого поста (10:40 по Москве), а не к моменту
запуска: бот, обновлённый в полночь, иначе высыпал бы ночью всё, чему
«уже пора». Если этот час на сегодня прошёл, отсчёт начинается завтра,
но первый пост выходит сразу — чтобы было видно, что серия пошла.

| День | Время (мск) | Пост |
|------|-------------|------|
| 1 | 10:40 | Что заказывают каждую неделю |
| 1 | 19:25 | Почему за одно и то же платят 300 и 3000 |
| 2 | 11:15 | Пять слоёв описания кадра |
| 2 | 16:05 | Почему кадр выглядит дёшево |
| 2 | 20:40 | Серия в одном стиле |
| 3 | 12:30 | Текст для уха, а не для глаз |
| 3 | 18:50 | Двенадцать секунд — это 300 знаков |
| 4 | 10:20 | Четыре проверки перед сдачей ролика |
| 4 | 15:45 | Себестоимость: почему 300 рублей — это минус |
| 4 | 21:10 | Первое сообщение заказчику |
| 5 | 11:50 | «Нейросеть же бесплатная, сам сделаю» |
| 5 | 17:35 | Портфолио из шести работ |

Часы нарочно неровные: посты ровно в 10:00 и 15:00 читаются как
расписание автомата. За один проход выходит не больше одного поста.

## Что уже вышло

```bash
sqlite3 /opt/kie_ai_bot/news.db \
  "SELECT key, published_at FROM seed_posts ORDER BY published_at;"
```

Повторный запуск ничего не дублирует: опубликованные ключи помечены в
базе, после перезапуска бот продолжает с того места.

Начать серию заново (например, в другой теме):

```bash
sqlite3 /opt/kie_ai_bot/news.db "DELETE FROM seed_posts; DELETE FROM seed_state;"
systemctl restart kie-bot
```

## Правка текстов

Тексты лежат в `group_seed.py`, в кортеже `POSTS`: день, время, ключ,
текст. Ключ — то, по чему пост считается опубликованным, менять его у
вышедшего поста не нужно. Разметка HTML (`<b>`), ссылок в постах нет:
в группе действует правило «чужих адресов нет», а счёт призывов к боту
ведут новости и промо.
