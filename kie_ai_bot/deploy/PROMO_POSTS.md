# Промо-посты про сервисы сайта

Раз в `PROMO_EVERY_DAYS` дней (по умолчанию 3) в канал выходит пост про один
из сервисов. Сервисы идут по кругу: берётся тот, что дольше всех не выходил.

К посту прикладывается **пример, сгенерированный через API прямо перед
публикацией**, а не заготовленная картинка.

## Сервисы и примеры

| Сервис | Страница | Что прикладывается |
|--------|----------|--------------------|
| Озвучка текста | `/tts-dashboard/` | аудио: фраза, озвученная голосом |
| Генератор звуков | `/sound-generator/` | музыкальный фрагмент по описанию |
| Говорящий аватар | `/govoryashchiy-avatar/` | кадр-портрет |
| Убрать шум | `/ubrat-shum/` | аудио: чистая речь |
| Убрать вокал | `/ubrat-vokal/` | инструментальная дорожка |
| NeuroHub | `/neurohub/` | сгенерированное изображение |

Тексты, пункты и описания примеров лежат в `promo_posts.py`, в списке
`SERVICES` — правятся без изменения логики.

## Если пример не сгенерировался

Модели иногда отвечают отказом: у Kie AI, например, синтез речи периодически
возвращает внутреннюю ошибку. На этот случай предусмотрен запасной путь:
вместо аудио генерируется иллюстрация, а если и она не выйдет — пост
публикуется текстом. Пост выходит в любом случае, отказ пишется в лог.

## Формат поста

```
Озвучка текста онлайн

Превращает любой текст в живую речь. Голос звучит естественно —
с паузами, ударениями и интонацией, а не как робот из навигатора.

• Несколько голосов и языков, включая русский
• Форматы MP3, WAV и Opus
• История генераций и доступ по API

Попробовать   ← ссылка на страницу сервиса
```

Следом отдельным сообщением идёт сам пример с подписью.

## Включение

```
PROMO_ENABLED=1
PROMO_EVERY_DAYS=3
```

Публикуется в тот же канал, что и новости (`NEWS_CHAT_ID`). После правки
`.env` — `systemctl restart kie-bot`. В логе появится
`[промо] запущено: раз в 3 дня, сервисов 6`.
