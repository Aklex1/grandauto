# Статьи-инструкции в блог

К каждому практическому кейсу в канале выходит подробный разбор на сайте.
В посте канала остаётся короткая выжимка и ссылка на статью с призывом
«Пошаговая инструкция по запуску». В статье — партнёрская ссылка на
хостинг (аренда VPS под проект) и ссылка на бота.

Статья оригинальная: собирается по шаблону под тему кейса (бот,
автоматизация, заработок, контент, проект). Чужой текст с сайта-источника
не копируется — берётся только тема кейса как повод.

## Что нужно один раз настроить

Публикация идёт через WordPress REST API. Нужен **пароль приложения**
(Application Password), а не пароль от админки — обычный пароль REST API
не принимает.

Создать пароль приложения:

1. Войдите в админку сайта под `adminka`.
2. **Пользователи → Профиль** (или `/wp-admin/profile.php`).
3. Внизу раздел **«Пароли приложений»** → имя, например `neurohub-bot` →
   **«Добавить пароль приложения»**.
4. Скопируйте показанный пароль (вида `xxxx xxxx xxxx xxxx`) — он
   показывается один раз.

Впишите его в `.env`:

```
WP_APP_PASSWORD=xxxx xxxx xxxx xxxx
WP_BLOG_USER=adminka
```

Пробелы в пароле можно оставить. Пароль можно в любой момент отозвать в
том же разделе — доступ к сайту у бота на этом закончится, основной пароль
менять не придётся.

## Настройки

| Переменная | Смысл | По умолчанию |
|---|---|---|
| `WP_APP_PASSWORD` | пароль приложения WP; пусто — статьи не публикуются | — |
| `WP_BLOG_USER` | автор статей | `adminka` |
| `WP_BLOG_CATEGORY_NAME` | рубрика (создаётся, если нет) | `Инструкции` |
| `WP_BLOG_CATEGORY_ID` | готовый id рубрики вместо имени | `0` |
| `HOSTING_AFFILIATE_URL` | партнёрская ссылка на хостинг | `https://beget.com/p2009255` |
| `HOSTING_AFFILIATE_ANCHOR` | анкор ссылки | `арендовать VPS` |
| `BLOG_ARTICLE_CTA` | призыв к ссылке на статью | `Пошаговая инструкция по запуску` |
| `NEWS_AFFILIATE_HOSTS` | партнёрские хосты, разрешённые в постах | `beget.com` |

## Если пароль не задан

Пост-кейс всё равно выйдет — без ссылки на статью. Партнёрская ссылка на
хостинг и ссылка на бота остаются: они не зависят от публикации статьи.

## Партнёрская ссылка в фильтре ссылок

В канале действует правило: чужих ссылок нет. Партнёрская ссылка на
хостинг — исключение, заданное явно в `NEWS_AFFILIATE_HOSTS`. Ставит её
только бот и только в практических постах; из лент такие ссылки по-прежнему
вырезаются.
