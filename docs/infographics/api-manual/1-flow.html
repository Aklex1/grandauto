Genius-bot API

Путь одного запроса

Схема одинаковая для всех операций: картинка, озвучка, музыка, видео.
1

Ваш код просит

Один POST с названием операции и описанием.

POST /genius/v1/generate "service": "image" "prompt": "кофе на столе"
⟶
2

Мы отвечаем номером

Сразу, за доли секунды. Деньги списываются здесь же.

"task_id": "2fd0f433…" "status": "pending" "cost": 9
⟶
3

Приходит файл

Обычно через 10–40 секунд, ссылка живёт на нашем сервере.

"status": "completed" "files": [{ "url": … }]
Способ А — спросить самому

Раз в 5 секунд дёргаете GET /tasks/<id>, пока статус не станет completed. Ничего настраивать не нужно — годится для скрипта и бота.

Способ Б — чтобы сообщили

Передаёте callback_url — мы сами постучимся на ваш адрес, когда файл готов, и подпишем запрос. Нужен свой сервер с белым адресом.

Деньги списываются в момент создания задачи. Если задача не удалась — возвращаются на баланс автоматически.
