# Инфографика к инструкции по API

Три картинки для статьи «Как автоматизировать рутину с помощью нейросети»
(`/kak-avtomatizirovat-rutinu-s-pomoshhyu-nejroseti-poshagovaya-instrukcziya-2/`):

| Файл | О чём |
|---|---|
| `1-flow.html` | путь одного запроса: задача → номер → готовый файл, опрос против вебхука |
| `2-evening.html` | сколько занимает каждый шаг: от ключа до бота на сервере |
| `3-map.html` | какие операции брать под задачу и сколько они стоят |

Картинки собраны разметкой, а не в редакторе: цену или название операции
правят в одной строке и пересобирают, а не перерисовывают заново.

## Пересобрать

```bash
python3 render.py
```

Скрипт открывает каждый файл в браузере и снимает блок `.sheet` в JPEG
шириной 1856 точек (1160 вёрстки при полуторном увеличении). Готовые
файлы грузятся в медиатеку и вставляются в статью как `figure.gs-shot`.

Цены берутся из живого ответа `GET /wp-json/genius/v1/services` — перед
пересборкой стоит свериться с ним, иначе в картинке останется вчерашний
тариф. В самой статье об этом сказано отдельной сноской: список операций
со свежими ценами всегда отдаёт сервис, а не картинка.
