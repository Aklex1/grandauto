# Передача проекта: контент-завод

## Доступ в панель

После установки скрипт печатает адрес, логин и пароль. По умолчанию:

- Адрес: `http://<IP сервера>/` (порт 80)
- Логин: `admin`
- Пароль: задаётся переменной `CF_ADMIN_PASSWORD` при установке, иначе генерируется
  и печатается в конце установки. Посмотреть позже: `grep CF_ADMIN_PASSWORD /etc/contentfactory.env`
- Сменить пароль: в панели «Настройки» → «Новый пароль администратора»

API-ключ KIE хранится в БД (раздел «Настройки») и в `/etc/contentfactory.env` (права 600).

## Текущее состояние после передачи

- **Автозапуск по расписанию ВЫКЛЮЧЕН.** Это сделано намеренно, чтобы завод не начал
  производить ролики без вашего ведома. Включается одним переключателем:
  «Настройки» → «Автозапуск по расписанию каналов». После включения планировщик каждые
  15 минут сверяется с расписанием канала и берёт следующие темы из контент-плана.
- Расписание по умолчанию: один ролик в день на каждый канал, запуск в 04:00 UTC.
  Меняется на вкладке «Расписание» канала.
- Мужской канал настроен на 7 минут, 8 сцен, 720p, вшитые субтитры и 3 шортса.
  Женский канал остался на настройках по умолчанию — проверьте его перед запуском.

## Первые шаги в панели

1. **Обзор** — баланс кредитов, статистика, очередь, ближайшие темы плана.
2. **Канал → Контент-план** — список книг с датами. Кнопка «Снять ролик» ставит тему в работу
   немедленно; «Дописать план через AI» добавляет новые темы текстовой моделью.
3. **Канал → Расписание** — сколько роликов и во сколько (UTC) генерировать по каждому дню недели.
4. **Канал → Настройки канала** — модели, голос с прослушиванием, формат, стиль,
   а также **оценка стоимости одного ролика** по актуальному прайсу KIE.
5. **Готовые видео** — плеер, скачивание MP4 / обложки / SRT / VTT, шортсы.
6. **Цены KIE** — весь прайс с поиском; обновляется автоматически раз в сутки в 03:20 UTC.

## Что важно знать про стоимость

Основная статья расходов — видеоряд. При настройках мужского канала
(7 минут, 8 сцен, 720p, клип 5 с, покрытие 20 с) выходит около **510 кредитов ≈ $2.5** за ролик.

Рычаги снижения цены:

| Что изменить | Эффект |
|---|---|
| «Секунд на клип» с 20 до 40 | клипов вдвое меньше → видеоряд дешевле вдвое, кадр однообразнее |
| Разрешение 720p → 480p | у `seedance-1.5-pro` 1.75 вместо 3.5 кредита/с — вдвое дешевле |
| Модель видео на `bytedance/seedance-1.5-pro` | самая дешёвая из линейки Seedance |
| Длительность ролика | стоимость почти линейна по минутам |

## Известные внешние ограничения

- **ElevenLabs через KIE на момент настройки отвечает `500 Internal Error`** на всех
  моделях и вариантах параметров — это сбой на стороне KIE, не в коде. Поэтому включён
  автоматический фолбэк на `google/gemini-3-1-flash-tts`, который корректно читает по-русски.
  Как только ElevenLabs у KIE починят, озвучка сама вернётся на него: предохранитель
  каждые 10 минут пробует основной провайдер заново. Проверить вручную можно кнопкой
  пересборки любого ролика.
- Сгенерированные файлы на стороне KIE живут 14 дней — завод скачивает их сразу к себе,
  так что это не влияет на архив.

## Производительность сборки

Сборка ролика упирается в CPU на этапах ffmpeg и распознавания речи. На 4 ядрах
7-минутный ролик занимает около 15–20 минут суммарно, из них примерно половина —
ожидание генерации на стороне KIE. Если роликов в день много, имеет смысл:

- увеличить `CF_WORKERS` (параллельные ролики) при запасе по ядрам;
- уменьшить `CF_WHISPER_MODEL` до `base` (быстрее, чуть менее точно) либо
  поднять `CF_WHISPER_DEVICE=cuda` при наличии видеокарты;
- поднять «Параллельных запросов на сцену» в настройках (лимит KIE — 20 запросов за 10 секунд).

## Резервное копирование

Достаточно сохранять два пути:

```bash
/var/lib/contentfactory/contentfactory.db     # вся база
/var/lib/contentfactory/media/                # готовые ролики и артефакты
```

Пример ежедневного бэкапа базы:

```bash
sqlite3 /var/lib/contentfactory/contentfactory.db ".backup '/root/cf-$(date +%F).db'"
```
