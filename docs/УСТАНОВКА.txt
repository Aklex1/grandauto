ИИ-АССИСТЕНТЫ GENIUS — УСТАНОВКА
================================

Всё готово к распаковке. Править чужие файлы не нужно нигде.

ШАГ 1. Распаковать архив в /genius-bot.ru/public_html/
------------------------------------------------------
Папка wp-content из архива ложится поверх существующей. Ничего не
перезаписывается: все три пути новые.

  wp-content/mu-plugins/genius-assistants-loader.php
      подключает модуль, не трогая kie-tts-wp.php.
      Обновление плагина теперь не сломает интеграцию.

  wp-content/mu-plugins/000-rest-basic-auth-fix.php
      чинит пароли приложений WordPress. Сейчас сайт на nginx + php-fpm
      не отдаёт ядру PHP_AUTH_USER, поэтому REST отвечает «Вы не авторизованы»
      даже на верный пароль. После этого файла заработает.

  wp-content/plugins/kie-tts-wp/modules/assistants/
      сам модуль: боты, веб-чат, админка, галерея.

  wp-content/uploads/genius-assistants/
      девять фоновых изображений для лендингов.

Активировать ничего не надо. Откройте любую страницу админки — таблицы
создадутся сами, в меню появится раздел «ИИ-ассистенты» с четырьмя
ассистентами первой волны.

ШАГ 2. Подключить ботов
------------------------
ИИ-ассистенты → Токены ботов. Создайте боты у @BotFather и вставьте токены.
Вебхук, команды и описание настроятся сами. Демон держать не нужно.

ШАГ 3. Страницы
----------------
Папка stranitsy — готовый HTML. Создайте страницы и вставьте содержимое
в режиме «Код»:

  01-glavnaya.html   → главная (или /ai-pomoshnik/)
  02-uchitel.html    → /ai-pomoshnik/dlya-uchitelya/
  03-ucheba.html     → /ai-pomoshnik/dlya-ucheby/
  04-yurist.html     → /ai-pomoshnik/yurist/
  05-biznes.html     → /ai-pomoshnik/dlya-biznesa/

  06-shapka.html     → это не страница. Вставить в Header Builder темы
                       Impreza элементом HTML и скрыть родное меню.

Если после шага 1 сделать пароль приложения для пользователя bot, страницы
и картинки зальются сами — командой python3 tools/wp_publish.py --images --pages
из репозитория. Тогда шаг 3 руками не нужен.

ПРО БАЛАНС
-----------
Своего счёта у модуля нет: он спрашивает баланс у kie-tts-wp и списывает
оттуда же. Чтобы связь была жёсткой, а не через определение колонок,
добавьте в kie-tts-wp две строки:

  add_filter('ga_balance_get',    fn($_, $uid) => kie_tts_get_balance($uid), 10, 2);
  add_filter('ga_balance_charge', fn($_, $uid, $sum, $note) => kie_tts_charge($uid, $sum, $note), 10, 4);

Подставьте настоящие имена ваших функций.

БЕЗОПАСНОСТЬ
-------------
Пароли FTP и администратора WordPress были присланы в переписку открытым
текстом. Смените их после установки.
