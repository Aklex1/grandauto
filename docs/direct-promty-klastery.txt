Рекламная кампания «Промты для фото»: разбивка по кластерам
===========================================================

Шаблон меток одинаков для всех групп, меняется только адрес посадочной.
В Директе его удобно задать один раз на уровне кампании — «Параметры
URL» в настройках, тогда он подставится ко всем объявлениям.

Хвост ссылки:
?utm_source=yandex&utm_medium=cpc&utm_campaign=promty-foto&utm_content={gbid}&utm_term={keyword}&kw={keyword}&mkw={matched_keyword}

  utm_source / utm_medium  — постоянные, для Метрики
  utm_campaign             — латиницей: кириллица в метках искажается
  utm_content={gbid}       — номер группы, то есть кластера
  utm_term={keyword}       — фраза, для отчётов Метрики
  kw={keyword}             — фраза для подбора карточек на странице
  mkw={matched_keyword}    — то же для автотаргетинга, где фразы нет

Зачем kw и mkw, если есть utm_term: utm-метки до сайта не доходят,
хостинг вырезает их из запроса ещё до обработки. В браузере они
остаются, Метрика их видит, а страница — нет. Поэтому фраза
дублируется своими именами. {keyword} и {matched_keyword} вместе
потому, что первый работает не во всех типах кампаний, а на
автотаргетинге ключевой фразы нет вовсе.
