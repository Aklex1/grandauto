# Архитектура контент-завода

## Общая схема

```
                    ┌────────────────────────────────────────────┐
   браузер ────────▶│ FastAPI (app/main.py)                      │
   (пароль)         │  сессия-cookie, серверный рендер Jinja2    │
                    └───────┬───────────────────────┬────────────┘
                            │                       │
                    ┌───────▼────────┐      ┌───────▼─────────────┐
                    │ БД (SQLAlchemy)│      │ Хранилище на диске  │
                    │ SQLite / PG    │      │ /var/lib/...media   │
                    └───────▲────────┘      └───────▲─────────────┘
                            │                       │
        ┌───────────────────┴────────┐              │
        │ Очередь задач (app/queue)  │              │
        │  N воркеров-потоков        │              │
        └───────┬────────────────────┘              │
                │                                   │
        ┌───────▼─────────────────────────┐         │
        │ Конвейер (app/pipeline.py)      │─────────┘
        └───┬───────┬────────┬────────┬───┘
            │       │        │        │
         KIE API  KIE API  ffmpeg  faster-whisper
        (чат/TTS/видео/картинки)
```

## Модули

| Файл | Ответственность |
|---|---|
| `app/main.py` | HTTP-маршруты, авторизация, рендер страниц, JSON-API |
| `app/models.py` | Схема БД (каналы, план, ролики, сцены, шортсы, задачи, события, цены, голоса) |
| `app/db.py` | Движок, сессии, `ensure_columns()` — лёгкая миграция схемы |
| `app/kie.py` | Клиент KIE: задачи генерации, чат, прайс, ретраи, разбор ответов |
| `app/pipeline.py` | Оркестрация производства ролика по этапам |
| `app/tts.py` | Озвучка: ElevenLabs → фолбэк Gemini TTS, предохранитель на сбои |
| `app/media.py` | ffmpeg: нормализация, ping-pong-зацикливание, сцены, склейка, шортсы |
| `app/music.py` | Фоновая музыка через Suno в KIE: генерация, кэш треков, переиспользование |
| `app/footage.py` | Библиотека своих видео: загрузка, подбор по тегам, нарезка непересекающихся фрагментов |
| `app/stock.py` | Бета: поиск и пакетный импорт футажей из Pexels и Pixabay |
| `app/kie.py` | Клиент KIE; `video_input` раскладывает поля запроса под семейство видеомодели |
| `app/pipeline.py` | Оркестрация сборки, в том числе пересборка одной сцены (`regen_scene`) |
| `app/subtitles.py` | Whisper + генерация SRT/VTT/ASS, склейка коротких реплик |
| `app/planner.py` | Контент-план → задачи по расписанию |
| `app/scheduler.py` | APScheduler: суточная синхронизация цен, проверка расписания |
| `app/sync.py` | Прайс KIE, список моделей, баланс, каталог голосов |
| `app/queue.py` | Очередь задач с атомарным захватом и восстановлением |
| `app/storage.py` | Пути, скачивание, размеры, ffprobe |
| `app/webutil.py` | Отдача медиа с поддержкой Range (перемотка видео) |
| `app/bootstrap.py` | Первичная инициализация: настройки, каналы, планы, голоса |

## Этапы конвейера

| Этап | Что делает | Прогресс |
|---|---|---|
| `script` | Чат-модель пишет сценарий и разбивает его на сцены | 10% |
| `voice` | Озвучка каждой сцены, файлы в `media/<канал>/<id>/audio/` | 35% |
| `visuals` | Клипы Seedance и/или фрагменты из библиотеки, `media/<канал>/<id>/clips/` | 65% |
| `assemble` | Каждая сцена — отдельный ролик с озвучкой и вшитыми субтитрами | 80% |
| `metadata` | Заголовок, варианты, описание, теги, фраза для обложки | 90% |
| `thumbnail` | Обложка nano-banana-2 с заголовком поверх (фолбэк — кадр сцены) | 93% |
| `scenes_ready` | Ждём выбора сцен в панели | 95% |
| сборка | Задача `assemble_final`: склейка выбранных сцен, музыка, общие субтитры | 100% |
| `shorts` | Отдельная задача: нарезка вертикальных фрагментов с заголовком | — |

## Устойчивость

- **Идемпотентность.** Этапы пропускаются, если артефакты уже есть **на диске**
  (проверяется существование файла, а не только запись в БД). Кнопка «Продолжить сборку»
  дожимает ролик с места остановки, не переплачивая за готовое.
- **Фолбэки.** Озвучка: второй провайдер. Обложка: кадр из ролика. Субтитры: тайминги по сценам,
  если ASR недоступен. Видеоряд: сцена без клипа берёт ближайший удачный.
- **Предохранитель.** Провайдер озвучки, упавший дважды подряд, выключается на 10 минут —
  остальные сцены сразу идут к рабочему движку.
- **Очередь.** Захват задачи через `UPDATE ... RETURNING` + блокировка в процессе: два воркера
  не возьмут одну задачу. При рестарте зависшие задачи возвращаются в очередь.
- **Ретраи.** HTTP 5xx/429 к KIE — три попытки с нарастающей паузой. Пустой ответ чат-модели
  или 524 от шлюза — до трёх повторов.

## Источники видеоряда

Каждой сцене нужно `ceil(длина озвучки ÷ «секунд на клип»)` кадров, не более шести.
Слоты распределяются между генерацией и библиотекой по режиму канала:

| Режим | Что происходит |
|---|---|
| `generate` | все кадры генерирует Seedance |
| `library` | все кадры режутся из загруженных футажей — бесплатно |
| `mix` | слоты чередуются согласно доле «процент из библиотеки» |

Фрагменты из библиотеки выбираются так, чтобы не пересекаться между собой в пределах ролика:
`SegmentPicker` хранит занятые интервалы по каждому файлу. Футажи ранжируются по совпадению
тегов с заголовком и описанием сцены, при равенстве — по числу прошлых использований,
чтобы библиотека расходовалась равномерно. Если библиотека пуста или фрагмент не удалось
вырезать, слот молча уходит в генерацию.

## Расчёт стоимости ролика

Стоимость определяется в основном видеорядом:

```
клипов = сумма по сценам ceil(длина_озвучки_сцены / «секунд на клип»)
кредиты ≈ клипов × длительность_клипа × тариф_модели_за_секунду
```

Для 7-минутного ролика на `seedance-1.5-pro` 720p без звука (3.5 кредита/с),
клип 5 с и покрытием 20 с: ≈ 24 клипа × 5 с × 3.5 ≈ 420 кредитов ≈ $2.1.
Ползунок «секунд на клип» в настройках канала — главный рычаг цены против разнообразия кадра.
