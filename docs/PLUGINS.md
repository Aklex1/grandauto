# Плагины сайта: что работает, что лежит мёртвым грузом

Разбор от 22 сентября 2026 года. Проверялось не по названиям, а по следам:
что реально печатается в разметку гостю, что настроено в самом плагине и
что вызывается из кода. Ниже — вывод по каждому активному плагину и
основания, по которым он сделан.

Всего в установке 36 плагинов: 19 включённых и 17 выключенных.

## Проверка

1. Разметка восьми страниц (главная, статья, каталог, раздел каталога,
   /api/, сервис, кабинет, лендинги) скачивалась без входа — у вошедшего
   страница не кэшируется и выглядит иначе.
2. Содержимое всех типов записей (`post`, `page`, `us_page_block`,
   `us_content_template`, `us_grid_layout`, портфолио, отзывы) искалось по
   шорткодам каждого плагина.
3. Настройки самих плагинов: сколько в них заведено элементов.
4. Файлы своих плагинов (`genius-pdf-online`, `wheel-fitment`,
   `kie-neurohub`, `kie-tts-wp`, `wp_optimize`) — 350 файлов — читались на
   предмет обращений к ACF.

## Insert PHP Code Snippet: выключать нельзя

В плагине лежит один активный сниппет `tg` с режимом «Automatic» — то есть
он исполняется на каждой загрузке страницы. Внутри — обработчик
`wp_ajax_nopriv_send_telegram_message`: форма обратной связи, которая
отправляет сообщение в Telegram владельцу. Форма стоит на странице
`/google-veo3/`. Выключишь плагин — форма перестанет отправлять, молча.

Заодно то, что видно в этом коде и стоит починить отдельно:

* токен бота вписан прямо в сниппет, а не в `wp-config.php` (в самом коде
  предусмотрена константа `TELEGRAM_BOT_TOKEN`, но она не задана);
* обработчик открыт всем (`nopriv`) без одноразового ключа и без
  ограничения частоты — любой может слать владельцу сообщения в Telegram
  сколько угодно, обычным запросом к `admin-ajax.php`.

Разумный ход — перенести этот обработчик в свой плагин, с ключом формы,
ограничением частоты и токеном в конфиге, и только после этого выключать
Insert PHP Code Snippet.

## Что ещё видно

* Обновления ждут 13 плагинов, из них семь включённых: Contact Form 7,
  Cookie Notice, Cyr-To-Lat, Inline Related Posts, Insert PHP Code Snippet,
  Sticky Buttons, Yandex Metrica. Формы и счётчики — обычная цель для
  чужого внимания, обновлять их стоит.
* Семнадцать выключенных плагинов лежат на диске: WooCommerce, Slider
  Revolution, Robokassa, FileBird, Akismet и прочее. Выключенный плагин
  кода не исполняет, но место занимает и обновляться не перестаёт. Удалять
  их — отдельное решение владельца, здесь только отмечено.
* В `robots.txt` указаны четыре карты сайта: `/wp-sitemap.xml` (ядро),
  `/sitemap.xml` (свой плагин), `/tts-sitemap.xml/` и
  `/sounds-sitemap.xml`. Карта ядра дублирует остальные — стоит убрать.
